# JKD-621-T23 开发环境搭建指南（已实测验证）

> 2026-09-16 在 Windows 11 + WSL2 Ubuntu 24.04 实测走通，产出完整固件
> `~/zkjh/Software/out/ZRT_SOC_T23ZN_GC2053_DIRECT_FW.bin`（13.8MB）。
> 本文档含全部踩坑记录，团队成员按步骤执行即可复现。

## 1. 前置条件
- Windows + WSL2 Ubuntu（`wsl --install` 后 `wsl -d Ubuntu`）
- SDK 与资料在 `D:\github\zkjh`（WSL 内路径 `/mnt/d/github/zkjh`）
- 磁盘：WSL 内 ≥10GB

## 2. 一键搭建（已封装脚本）
```bash
# 在 Windows PowerShell:
wsl -d Ubuntu -- bash /mnt/d/github/zkjh/mvp/scripts/wsl_setup_env.sh
```
脚本自动完成：依赖安装(p7zip-full/bzip2/lbzip2/build-essential/lzop/u-boot-tools/cpio)、
SDK 拷贝到 `~/zkjh/Software`（原生文件系统，勿在 /mnt/d 上编译，速度差 10 倍）、
工具链解压、`.env` 生成、7z 全量解包、符号链接修复。

## 3. 编译固件
```bash
# 当前默认配置已切到 TP9950:
wsl -d Ubuntu -- bash /mnt/d/github/zkjh/mvp/scripts/wsl_tp9950_patch4.sh
# 或手动:
wsl -d Ubuntu
cd ~/zkjh/Software
set -a; source .env; set +a
export PATH=~/zkjh/toolchain/bin-gnu:$PATH
./build/build_camera_all.sh
```
产物：`out/ZRT_SOC_T23ZN_TP9950_DIRECT_FW.bin` + `out/camera/` 下 6 个分区文件
（boot/tag/uImage/rootfs/recovery/system）。
TP9950 驱动集成细节与来龙去脉见《03_完整构建与烧录流程.md》。
## 4. 踩坑记录（重要！新人必读）
| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | `No rule to make target 'export'` | build_camera_uImage.sh 用 `cat .env \| xargs make`，.env 里不能出现 export 字样 | .env 必须是纯 `VAR=value` 格式；shell 里用 `set -a; source .env; set +a` 导出 |
| 2 | `fatal error: isp-t23/include/fast_start_common.h` | Makefile 引用 `$(ZRT_ENV_KERNEL_DIR)` | .env 加 `ZRT_ENV_KERNEL_DIR=~/zkjh/Software/os/kernel` |
| 3 | `No rule to make target 'libtxisp-t23-ms-direct.hex'` | 多摄库不存在 | .env 的 `ZRT_ENV_SENSOR_MULTI_MAX=` 留空（单摄） |
| 4 | `lzop: not found` / `mkimage not found` | 缺宿主工具 | `apt install lzop u-boot-tools` |
| 5 | `cpio: command not found`→rootfs 只有 20B | 缺 cpio | `apt install cpio` 后删除 out/camera/rootfs* 重编 |
| 6 | `crc32: command not found` | SDK 仅用于打印校验 | 已放 /usr/local/bin/crc32 python shim |
| 7 | `Please enter ./build/build_camera_rootfs -f` | 缺内核版本变量 | .env 加 `ZRT_ENV_KERNEL_RELEASE=3.10.14-Archon` |
| 8 | 7z 解包报 Dangerous symlink ignored | p7zip 安全策略 | setup 脚本已手动补 dt-bindings/profiles 链接 |
| 9 | wsl.exe 传参会吞 `$` 变量 | PowerShell/WSL 边界 | 一律用 `bash /mnt/d/.../xxx.sh` 脚本方式 |

## 5. 工具链
- mips-gcc540-uclibc（Ingenic 官方，位于 `~/zkjh/toolchain/`）
- 二进制前缀 `mips-linux-uclibc-`，SDK 脚本要 `mips-linux-gnu-` → `bin-gnu/` 已建符号链接映射
- 验证：`mips-linux-gnu-gcc --version` 应显示 5.4.0 (Ingenic)
