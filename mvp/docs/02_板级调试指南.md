# JKD-621-T23 开发板调试指南（回答：如何进入系统/没有HDMI怎么看）

## 1. 这块板没有 HDMI/LCD 是正常的
T23 是嵌入式 MIPS 视频处理器（IPC 平台），调试方式是 **串口控制台 + 网络**，
不需要也不支持显示器。所有"界面"都在你的 PC 上看。

## 2. 进入系统（串口控制台）—— 最重要的一步
### 2.1 需要的硬件
- USB-TTL 串口线（3.3V 电平！CP2102/CH340/FT232 均可；
  君正原厂调试板 RD_JZ_USBDEBUG V1.0/V1.2 在 `ISVP.../software/pc/Uart/`）
- 接线：板上 **J14（日志/控制台）** 引出 T23 UART1_TXD(PB23)/UART1_RXD(PB24)
  - 串口线 RXD ← 板 TXD；串口线 TXD → 板 RXD；GND ↔ GND
  - **J17** 是程序下载调试口（T23 UART1 + HC32 SWDIO/SWCLK/RESET 二合一，5P）
### 2.2 终端参数
- 波特率 **115200**，8N1，无流控（Windows 用 MobaXterm/SecureCRT/Xshell）
### 2.3 上电后看到什么
- U-Boot 打印 → 内核启动 log（dmesg）→ busybox shell 提示符（root，无密码）
- 出 shell 即"进入系统"，可执行 ls/cat/insmod/ifconfig 等全部 busybox 命令
- 修改启动参数/调试内核：开机 1s 内在串口按键打断 U-Boot 进 boot 命令行

## 3. 没有显示器，怎么看图像？
在 PC 上看：开发阶段用 SDK 自带的 carrier-server 出 RTSP 流：
```bash
# 板子串口 shell 里（先用 USB 网卡/以太网配好 IP）:
./carrier-server --st=gc2053 &
# PC 上 VLC 打开: rtsp://<板子IP>:8554/main
```
（TP9950/AHD 通道适配后同理，--st 换成 tp9950）

## 4. 网络接入（开发期）
- 板上无网口、无 WiFi 焊接 → 用 **USB 转 Ethernet**（AX88772，SDK 内核已含驱动，
  《INDUS开发板使用说明》2.1 节接线图）；或 USB RNDIS 连 PC
- 系统默认启动了 **telnetd**：PC `telnet <板子IP>` 登录（比串口快，可传文件）
- TF 卡：`insmod_mmc` 后挂载在 `/tmp/mnt/sdcard`

## 5. 三个调试口速查（依据原理图）
| 口 | 引脚 | 用途 |
|---|---|---|
| J14 | T23 UART1_TXD/RXD | Linux 控制台/日志打印（115200） |
| J17 | T23 UART1 + HC32 SWDIO/SWCLK + RESET | T23 日志 + HC32 固件下载（Keil/HC32 烧录器接 SWD） |
| J6 | HC32 PA00/PA01(燃气TXD/RXD) + 5V | 燃气模块接口（也可接 USB-TTL 用 gas_sim.py 模拟） |

## 6. 分区与文件系统（改东西放哪）
NOR 16MB：boot | tag | kernel | rootfs(只读,lzo) | recovery | system(squashfs) | **config(jffs2 可写)**
- 运行时可改配置 → `/config`（免重烧，FR-06 落点）
- 应用程序放 `/system/bin`，开机自启改 rootfs 的 `/etc/init.d/rcS`

## 7. 常用调试命令（来自系统调试命令集文档）
- 出流检测：`dmesg | grep TTFF`
- 时钟/传感器状态：`impdbg`、`logcat`
- GPIO：`cat /sys/class/gpio/...`
- 看门狗/MCU 通信：TRANSFER_MODE 环境变量（当前 IIC，我板为 UART 需改 rcS）
