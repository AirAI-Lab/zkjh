# 完整构建与烧录流程（端到端，2026-09-22 实测）

> 目标：新成员从零环境 → 产出 TP9950 固件 → 烧到板子 → 串口看到系统。

## 阶段 1：环境搭建（一次性，约 10 分钟）
```powershell
wsl -d Ubuntu -- bash /mnt/d/github/zkjh/mvp/scripts/wsl_setup_env.sh
```
自动完成：依赖安装 / SDK 拷贝到 ~/zkjh/Software / 工具链解压 / .env 生成 / 7z 解包 /
符号链接修复。详细坑位见《01_环境搭建指南》。

## 阶段 2：编译 TP9950 固件（约 3 分钟，增量）
```powershell
wsl -d Ubuntu -- bash /mnt/d/github/zkjh/mvp/scripts/wsl_tp9950_patch4.sh
```
产物：`~/zkjh/Software/out/ZRT_SOC_T23ZN_TP9950_DIRECT_FW.bin`
（已有一份存档：`mvp/releases/ZRT_SOC_T23ZN_TP9950_DIRECT_FW.bin`）

### TP9950 驱动的来龙去脉（为什么要这样做）
1. 君正参考 `tp9951.c`（ISVP 风格：module_init/THIS_MODULE）→ 拷入
   `~/zkjh/Software/os/drivers/sensor-t23/zeratul/single_camera/tp9950/tp9950.c`
2. 三处适配：
   - 符号重命名 tp9951→tp9950；
   - detect() 芯片 ID 双兼容（0x2850=TP9950 / 0x2860=TP9951，上板后固定）；
   - **尾部追加 Zeratul 内建封装**（get_sensor_name / get_sensor_i2c_addr(0x44) /
     get_sensor_width/height / init_sensor / exit_sensor），并**删除**
     module_init/module_exit/module_param/MODULE_*/THIS_MODULE——Zeratul 的 ISP 通过
     `isp-t23/<sensor>.hex`（实为 ELF .o）把 sensor 内建进 vmlinux，模块符号会链接失败。
3. `make` 产出 sensor_tp9950_t23.ko + tp9950.o；`cp tp9950.o .../isp-t23/tp9950.hex`
4. `.env` 中 `ZRT_ENV_SENSOR=tp9950` → `build_camera_all.sh` 全量出固件。

### 切换其他 sensor（对照实验用）
改 `.env` 的 `ZRT_ENV_SENSOR/ZRT_ENV_SENSOR0`（如 gc2053），删除
`out/camera/uImage.jzlzma` 与 `out/*.bin` 后重跑 `build_camera_all.sh`。

## 阶段 3：烧录
工具：USB-cloner 2.5.35（`ISVP.../software/pc/USB-cloner-*.tar.gz` 解压安装 Windows 版）
1. 板子断电，BootSel 按住/短接 → USB 上电 → USB-cloner 识别设备
2. 导入固件 bin → 烧录（约 1-2 分钟）
3. 烧完断电、恢复 BootSel、重新上电
备选：系统正常启动后 TF 卡 `flashcp` 分区烧录；变砖时 SD 卡启动 `fatload` 抢救
（详见《Ingenic_Zeratul_T23_烧录说明.pdf》）。

## 阶段 4：上电验证（按顺序，全部在串口里看）
```
[ ] 1. J14 接 USB-TTL(115200-8N1) → U-Boot 打印出现
[ ] 2. 内核日志 → busybox shell 提示符
[ ] 3. dmesg | grep -i tp9950  → 看 probe: 芯片ID(0x28xx)、检测到的制式
[ ] 4. i2cdetect -y 0          → 0x44 有应答
[ ] 5. ls /dev/video*          → 视频节点存在
[ ] 6. ifconfig usb0 / udhcpc  → RNDIS/网口通（配好后 telnet 192.168.x.x）
[ ] 7. ./carrier-server --st=tp9950 & → PC VLC 开 rtsp://<IP>:8554/main 看到 AHD 画面
```
任一步失败 → 对照《02_板级调试指南》排障 + 记录到决策日志。

## 阶段 5：通道切换验证（W2 核心实验）
当前驱动 `tp9950_init()` 固定 VIN1（`TP9950_sensor_init(sd, VIN1, ...)`）。
实验步骤（串口下）：
1. `i2cset -y 0 0x44 0x40 0x00`（回解码页）
2. `i2cset -y 0 0x44 0x41 0x01`（切 VIN2）
3. 读 `0x03` 直到稳定（制式码），对比驱动 probe 逻辑
4. 记录：切换→出流稳定耗时 ×4 通道 → 写入决策日志（抓拍时间预算的实测依据）
之后把 ch 参数做成 sysfs/proc 接口（W2 开发项，半天）。
