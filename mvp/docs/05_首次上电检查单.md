# JKD-621-T23 首次上电检查单（板到手后按此执行）

> 前置：固件已备好 `mvp/releases/ZRT_SOC_T23ZN_TP9950_DIRECT_FW.bin`；
> 工具：USB-TTL(CH340/CP2102, 3.3V 电平)、USB-cloner 2.5.35、杜邦线、电池/太阳能或桌面电源。

## 0. 接口对照（依据原理图 + 烧录口.png 照片核对）
| 板上接口 | 丝印/信号 | 用途 |
|---|---|---|
| **J14（调试打印日志口）** | GND / TX0 / RX0（T23 UART1: PB23=TXD, PB24=RXD） | Linux 控制台 115200-8N1 ← **首选接这里**（照片中可见 GND/TX/RX 丝印排针） |
| **J17（程序下载调试口）** | T23 UART1_TXD/RXD + HC32 SWDIO/SWCLK + RESET (5P) | HC32 固件烧录(SWD) + 兼作 T23 日志 |
| T23 固件烧录 | 板上 USB 口（USB0_DP/DM，与 ML307R 共用） | USB-cloner 烧录 ⚠ 见第 3 节注意事项 |
| J6 | HC32 PA00/PA01 + 5V | 燃气模块（或接 USB-TTL 跑 gas_sim.py 模拟） |

接线（以 J14 为例）：USB-TTL 的 RXD ← 板 TX0；USB-TTL 的 TXD → 板 RX0；GND↔GND。
（TX/RX 接反不会损坏，无输出时对调即可。）

## 1. 上电前
- [ ] 目检：短路、连锡、极性（J10 电池 / J8 太阳能）
- [ ] 首次不插 SIM 卡（减少变量）
- [ ] USB-TTL 接好 J14，PC 装好驱动，设备管理器确认 COMx

## 2. 首次上电（先看启动，不烧录）
```powershell
python D:\github\zkjh\mvp\scripts\serial_monitor.py --port COMx
```
- [ ] 看到 U-Boot 打印 → 内核 log → busybox shell 提示符
- [ ] 记录启动总耗时（快起基线）
- [ ] `dmesg | grep -i tp9950` → 芯片 ID(0x28xx) + 制式检测结果
- 无输出时排障：TX/RX 对调 → 供电电压 → 波特率 → 按住 BootSel 上电试 boot 模式

## 3. 烧录 TP9950 固件（USB-cloner 2.5.35）
⚠ **注意事项**：T23 USB0 与 ML307R 共用 DP/DM 线。烧录前确保模组处于关机/断电状态
（不插 SIM 且确认模组未开机；不确定时先断模组供电轨再烧）。
- [ ] 断电 → 按住 BootSel → USB 上电 → USB-cloner 识别设备
- [ ] 导入 ZRT_SOC_T23ZN_TP9950_DIRECT_FW.bin → 烧录（1~2 分钟）→ 断电恢复 BootSel
- [ ] 重新上电 → 重复第 2 步验证

## 4. TP9950 出流验证
- [ ] `dmesg | grep TTFF`（出流标记）
- [ ] 配网络（USB 转网卡 AX88772 或 RNDIS）→ `telnet <板IP>`
- [ ] `./carrier-server --st=tp9950 &` → PC 用 VLC 打开 `rtsp://<板IP>:8554/main`
- [ ] 失败排障顺序：`i2cdetect -y 0` 看 0x44 → TP9950 三路供电(2.8V/1.1V/1.8V) →
      MIPI lane 映射/极性 → 复位脚 PA18 电平

## 5. 通道切换实测（W2 核心数据）
```bash
i2cset -y 0 0x44 0x40 0x00    # 回解码页
i2cset -y 0 0x44 0x41 0x01    # 切 VIN2 (0x00/0x01/0x02/0x03 = 通道A/B/C/D)
# 轮询读 0x03 至稳定, 记录耗时; 4 通道各测 3 次取均值
```
结果写入 `docs/决策与历史记录.md`（作为抓拍时间预算的实测依据）。
